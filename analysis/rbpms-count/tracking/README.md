# tracking/

The tracking log (`animals.csv`, `status.csv`, `STATUS.md`) lists real animals, so it is **never committed**:
the lab repo is public, and `.gitignore` blocks everything here except this README and the example.

- Start: copy `animals.example.csv` to `animals.csv` and replace the rows.
- Share with the lab: keep the log in a shared folder (e.g. on CRSP) and set `RBPMS_TRACKING` to that folder
  (see the main README, "Tracking which animals are done").
